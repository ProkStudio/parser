# Parser 0.2.0 — desktop preview

- Три вкладки: Аккаунты, Прокси, Задачи. Фильтры и результаты — в отдельных окнах.
- Запуск отдельным окном WebView, без автоматического открытия браузера.
- Локальный выбор нескольких Telethon .session или папки tdata. Отчёт об импорте и защита от дубликатов.
- SOCKS5 / HTTP CONNECT с привязкой к аккаунту, проверкой туннеля и без прямого fallback.
- Задача закреплена за аккаунтом; продолжение раздельно для аккаунтов.
- Прежний локальный аккаунт и задачи сохранены. Перед обновлением сделайте резервную копию папки данных.

Экспериментальная неподписанная версия. Автотесты используют синтетические данные. Живой вход и сбор Telegram ещё не проверялись. Чтение tdata зависит от неподдерживаемого opentele и может не работать с новыми форматами Telegram Desktop. Запасной вариант — вход по номеру с кодом и 2FA.

Новая MSI не публикуется автоматически: перед распространением нужно проверить Windows-сборку и лицензии включённых зависимостей, особенно PyQt5. Старый релиз 0.1.0 не содержит эти изменения.
