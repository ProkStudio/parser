## Parser 0.1.0 — Windows preview

- Чёрно-золотой интерфейс без сводной статистики.
- Встроенная пошаговая инструкция с четырьмя реальными скриншотами интерфейса на учебных данных.
- Очередь сборов, фильтры, атомарные чекпоинты, пауза/продолжение и экспорт CSV/JSON/JSONL.
- MSI для Windows 10/11 x64: Python включён, ярлык в меню Пуск, обычное удаление через Windows.
- Установка, запуск установленного приложения, встроенные изображения, ярлык и удаление проверяются автоматически перед публикацией. Данные пользователя при удалении сохраняются.

**Предварительная, неподписанная сборка.** Проверяйте SHA-256 из соседнего файла. Не отключайте защиту Windows. Авторизацию и чтение Telegram нужно проверить со своим аккаунтом; автоматические функциональные тесты используют синтетический адаптер. Импорт .session/tdata, мультиаккаунты и мониторинг по расписанию пока не поддерживаются.

Не отправляйте разработчикам свои коды входа, API Hash, файлы сессий или папку tdata. Инструкция доступна прямо в приложении.
