# Parser

Локальное Windows-приложение для чтения сообщений из доступных Telegram-каналов и групп. Чёрно-золотой интерфейс без панели статистики, очередь задач, поиск, экспорт и встроенная инструкция с четырьмя скриншотами.

**Статус: предварительная версия 0.1.0.** Автоматические тесты используют учебные данные; реальный вход и доступ к конкретным каналам необходимо проверить со своим аккаунтом. Импорт `.session` и `tdata` в этой версии не реализован. Это не инструмент рассылок, сбора участников или обхода доступа.

## Для пользователя Windows

1. Откройте раздел **Releases** этого репозитория и скачайте `Parser-0.1.0-x64.msi` из проверенной preview-сборки.
2. Установите приложение и запустите **Пуск → Parser**. Python и командная строка не нужны. Интерфейс откроется в браузере на локальном адресе.
3. Откройте **Инструкция** внутри приложения. Там есть порядок установки, подключения, настройки фильтров, управления очередью и экспорта, а также увеличиваемые скриншоты.
4. Для входа нужны собственные API ID / API Hash с `my.telegram.org/apps`, код Telegram и, если включён, пароль 2FA.

Установщик предварительной версии **не подписан сертификатом**. Проверяйте источник и SHA-256 по `SHA256SUMS.txt`; не отключайте защиту Windows. Поддерживается Windows 10/11 x64, установка для текущего пользователя.

Удаление: **Параметры Windows → Приложения → Parser**. Личные данные в `%LOCALAPPDATA%\Parser` остаются: установщик их намеренно не удаляет.

## Возможности и ограничения

- До 20 источников за запуск; одна задача выполняется за раз.
- Включающие/исключающие фразы, период UTC, тип медиа, до 50 000 просмотренных сообщений на источник.
- От старых сообщений к новым; верхняя граница истории фиксируется в начале задачи.
- Пауза, продолжение, отмена, повтор после ошибки. SQLite-чекпоинт записывает сообщения и позицию атомарно.
- Дедупликация по источнику и ID сообщения, обновление существующих записей при повторном чтении.
- Ограничения Telegram (FloodWait) выдерживаются и сохраняются при перезапуске.
- Unicode-поиск, выбор источника, страницы результатов; экспорт всей выборки в CSV, JSON или JSONL.
- CSV защищён от формул в тексте. Медиа не скачиваются, сохраняются текст, метаданные и ссылка.
- Нет фонового мониторинга в реальном времени, планировщика, мультиаккаунтов, импорта сессий и облачной синхронизации. Для новой части истории создайте следующий сбор.

**Важно:** лимит действует до фильтров. Сохранённая позиция учитывает и сообщения, не прошедшие фильтр. Чтобы изменить фильтры и перечитать прошлую историю, снимите «Продолжать с сохранённой позиции».

## Данные и безопасность

Сервер слушает только `127.0.0.1`. API требует случайный ключ запуска, проверяет Host/Origin и не разрешает CORS. Ключ передаётся браузеру во фрагменте URL, затем удаляется из адреса и хранится только в сессии вкладки. В папке профиля есть закрытый файл запуска для повторного открытия приложения.

API Hash и Telegram-сессия остаются в локальной папке. Код и пароль 2FA не записываются в журнал или базу. **Данные не шифруются приложением**: используйте шифрование диска и защищённую учётную запись ОС. Не передавайте файлы сессий и папку данных третьим лицам. Локальные процессы той же учётной записи находятся за пределами этой модели защиты.

Закрытие вкладки не останавливает процесс. Для полного выхода используйте **Подключение → Завершить приложение**. Выполнявшаяся задача сохраняет позицию и остаётся на паузе.

## Запуск из исходников

Python 3.11+:

```powershell
py -m venv .venv
.\.venv\Scripts\python -m pip install .
.\.venv\Scripts\python -m parser_app
```

На Linux/macOS: `python3 -m venv .venv`, затем `.venv/bin/python -m pip install .` и `.venv/bin/python -m parser_app`. Папка по умолчанию: `~/.local/share/parser` (или `$XDG_DATA_HOME/parser`).

Дополнительные параметры: `--data-dir PATH`, `--port NUMBER`, `--no-browser`.

Иллюстрации инструкции генерируются из реального интерфейса на синтетическом тестовом сервере и включены в MSI. Для разработки или сборки исходного пакета с иллюстрациями:

```bash
python -m pip install Pillow==11.2.1
npm install --no-save playwright@1.51.1
npx playwright install chromium
node tests/browser.mjs
```

При нестандартном имени Python задайте переменную `PYTHON`. `CHROMIUM_EXECUTABLE` позволяет использовать установленный Chromium. Ни один сценарий генерации не обращается к настоящему Telegram.

## Проверки и сборка MSI

```bash
python -m unittest discover -s tests -v
node tests/browser.mjs
```

Для MSI нужен Windows и Python 3.12 x64. После генерации иллюстраций:

```powershell
python -m pip install . cx_Freeze==8.6.4 Pillow==11.2.1
python tools/build_icon.py
python tools/freeze.py bdist_msi
```

Готовый файл: `dist/Parser-0.1.0-x64.msi`. GitHub Actions дополнительно устанавливает MSI на чистом Windows runner, запускает установленный EXE, проверяет все встроенные файлы и ярлык, удаляет приложение и проверяет сохранность личных данных. Preview-релиз публикуется **только после успешных проверок**, без слияния ветки в `main`.

Основные модули: `domain.py` — валидация/фильтры/экспорт; `store.py` — SQLite; `telegram.py` — Telethon; `engine.py` — очередь; `server.py` — локальный API; `static/` — интерфейс. Учебный адаптер находится только в `tests/` и в установщик не включается.
