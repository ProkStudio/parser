Добавить аккаунт

Выберите способ. Файлы не нужно загружать в GitHub или отправлять кому-либо.

Выберите один или несколько файлов Telethon .session. Pyrogram и StringSession не поддерживаются. Закройте программу, которая использует эти файлы.

Укажите параметры приложения, с которыми создана сессия. Файл .session не содержит API ID и API Hash.

Закройте Telegram Desktop. Выберите саму папку tdata, внутри которой есть key_data. ZIP сначала распакуйте.

Это код блокировки приложения, не облачный пароль 2FA. Ключи API вручную не нужны.

Экспериментальный импорт через opentele: новые форматы tdata могут не поддерживаться. Надёжный запасной способ — вход по номеру.

Войдите с API ID и API Hash, номером телефона и кодом из Telegram. Пароль 2FA потребуется, если он включён.

Выбор файлов доступен в отдельном окне Parser. Этот режим браузера предназначен только для разработки.

Фильтры и лимиты

Результаты

Быстрый старт

  1. Аккаунты → Добавить аккаунт

    Выберите .session, папку tdata или вход по номеру. Импорт только копирует ключ в локальное хранилище. Нажмите «Проверить» для подключения.

  2. Прокси → Добавить прокси

    При необходимости добавьте SOCKS5 или HTTP CONNECT. Назначьте его в строке аккаунта через «Настройки». Прокси необязателен.

  3. Задачи → Новая задача

    Выберите проверенный аккаунт и источники. Фильтры спрятаны в «Фильтры и лимиты». Результаты и экспорт доступны здесь же.

Безопасность и ограничения

Импортированная сессия — тот же доступ, что и в исходном приложении. Не используйте одну копию одновременно на разных устройствах. Удаление аккаунта из Parser не отзывает сессию в Telegram. При утечке завершите её в Telegram → Настройки → Устройства.

tdata читается через opentele, который автор больше не поддерживает. Совместимость не гарантируется. Если папка не читается, используйте вход по номеру, не отключая 2FA.

Программа только читает сообщения каналов и групп. Не собирает телефоны участников, не рассылает сообщения. Отдельного обхода лимитов или переключения аккаунтов для обхода FloodWait нет.

При закрытии окна текущая задача сохраняется на паузе. Возобновите её после следующего запуска.
