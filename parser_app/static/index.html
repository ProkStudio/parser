Как пользоваться Parser

Пять шагов без лишних настроек. Инструкция работает без интернета; для самого сбора нужен доступ к Telegram.

На скриншотах — интерфейс этой версии с учебными именами и сообщениями, не реальные данные аккаунта. Нажмите на изображение, чтобы открыть его крупнее.

01Установите и откройте приложениеWindows 10 / 11 · x64
  1. Скачайте файл Parser-0.1.0-x64.msi из релиза этого проекта и запустите его. Не используйте установщики из случайных источников.
  2. Подтвердите установку. Она выполняется для вашей учётной записи Windows; отдельная установка Python не нужна.
  3. Откройте Пуск → Parser. Интерфейс появится в браузере по локальному адресу. Не передавайте другим личную ссылку запуска.

Если Windows предупреждает о неизвестном издателе: эта предварительная сборка не подписана сертификатом. Сверьте SHA-256 с файлом контрольных сумм релиза; не отключайте защиту Windows.

Вторая попытка запуска открывает уже работающий Parser. Для полного выхода используйте «Подключение → Завершить приложение»; закрытие вкладки само по себе не останавливает сбор.

02Подключите свой TelegramAPI-параметры, код и при необходимости 2FA
  1. Откройте вкладку Подключение. На my.telegram.org/apps создайте API-приложение и скопируйте его API ID и API Hash. Токен бота не подходит.
  2. Сохраните параметры, затем введите свой номер в формате +79991234567.
  3. Введите код, который прислал Telegram. Если включена двухэтапная аутентификация, дополнительно введите пароль 2FA. Дождитесь надписи «Telegram подключён».

В этой версии используется вход по коду. Файлы Telethon .session и папка Telegram Desktop tdata — разные форматы; их импорт через интерфейс пока не поддерживается. Не заменяйте рабочую сессию случайным файлом.

При повторном запуске сохранённая сессия подключается автоматически. Код и пароль 2FA не сохраняются в базе или журнале. Файл сессии даёт доступ к аккаунту — не отправляйте его в чат и не загружайте на сайты-конвертеры.

03Настройте первый сборИсточники → фразы → период
  1. Откройте Сбор. Добавьте до 20 каналов или групп, по одному на строку: @channel_name либо https://t.me/channel_name. Для доступной приватной супергруппы можно использовать её ID -100….
  2. В поле Содержит фразы перечислите нужные фразы через запятую. Достаточно совпадения любой из них. Поле Исключить фразы убирает сообщение при любом совпадении. Регистр не важен; пустые поля означают отсутствие фильтра.
  3. Раскройте Период и параметры сбора: выберите даты по UTC, тип сообщения и лимит просмотра от 1 до 50 000 на каждый источник.
  4. Нажмите Начать сбор. Для первого теста удобно оставить лимит 1000.

Лимит считается до применения фильтров: просмотрено 1000 сообщений, а сохранено может быть только 10. Сбор идёт от старых сообщений к новым; новые публикации после старта попадут в следующий запуск. Медиафайлы не скачиваются — сохраняются текст, тип и ссылка на оригинал.

Повтор с другими фильтрами: снимите «Продолжать с сохранённой позиции». Иначе ранее просмотренная история, включая исключённые сообщения, не будет проверяться заново. Дубликаты обновляются, а не размножаются.

04Управляйте очередьюПауза, продолжение и ошибки
  • В очереди — ждёт предыдущую задачу. Одновременно выполняется один сбор.
  • Пауза — сохраняет позицию. Продолжить возвращает задачу в очередь без повторной обработки уже просмотренного.
  • Ждём Telegram — сервис ограничил частоту запросов. Parser выдержит паузу сам; перезапуск её не обнулит.
  • Ошибка — прочитайте причину, устраните её и нажмите Повторить. При потере авторизации сначала подключите Telegram заново.
  • Отменить — останавливает задачу, но оставляет уже сохранённые сообщения. Для следующей части истории создайте новый сбор.

После аварийного закрытия выполнявшаяся задача появится на паузе. Последний незаписанный пакет может быть перечитан; уникальный ключ сообщения предотвращает дубликаты. Во время медленного сетевого запроса остановка может занять несколько секунд.

05Найдите и выгрузите результатПоиск, CSV, JSON и JSONL
  1. Откройте Сообщения. Введите часть текста или выберите источник. Поиск не учитывает регистр, в том числе в русском тексте.
  2. Раскройте длинное сообщение или нажмите В Telegram, чтобы открыть оригинал. Новые сообщения показываются первыми; время указано по UTC.
  3. Выберите CSV · Excel, JSON или JSONL и нажмите Экспорт. Выгружается вся текущая выборка, а не только открытая страница.

CSV использует UTF-8 с меткой BOM для Excel. Опасные начала строк экранируются, чтобы текст сообщений не выполнялся как формула. JSON и JSONL сохраняют исходный текст без такого экранирования.

Если что-то не получается

  • «Не подключён»: проверьте интернет и нажмите «Подключение → Проверить сессию». Отозванная сессия требует нового входа.
  • «Нет доступа»: источник должен быть доступен именно подключённому аккаунту. Parser не вступает в группы и не обходит ограничения.
  • Пустая выборка: проверьте фразы, период UTC и выбранный тип. Для повторной проверки старой истории отключите продолжение с сохранённой позиции.
  • «Ключ устарел»: откройте Parser из меню Пуск. Не используйте старую закладку с предыдущего запуска.
  • Удаление приложения: Windows → Параметры → Приложения → Parser → Удалить. Личные данные остаются в %LOCALAPPDATA%\Parser; база и сессия не удаляются установщиком. Историю можно отдельно очистить в приложении. Сессию отзывают через «Отключить аккаунт» или Telegram → Устройства.

Приложение не шифрует локальную базу. Защищайте учётную запись Windows и диск; делайте резервную копию папки данных только после полного выхода из Parser и храните её как конфиденциальную.
